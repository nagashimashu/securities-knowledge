# 証券業務ナレッジ入門

証券会社の仕事を、**はじめて学ぶ人・他部署の人**向けにやさしく解説するサイトです。
内容はすべて公的機関・業界団体が公開している一次情報にもとづき、各記事に出典と最終確認日を載せています。

!!! info "このサイトは投資勧誘・投資助言を目的としたものではありません"
    個別の銘柄や金融商品をおすすめすることはありません。詳しくは[免責事項](about/disclaimer.md)をご覧ください。
