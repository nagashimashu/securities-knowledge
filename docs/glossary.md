# 用語集

入門者がつまずきやすい用語を、五十音順にまとめています。定義は要点だけを示しているので、詳しくはリンク先の記事と、その記事の出典をご覧ください。本文中の一部の略語は、マウスを重ねると説明が表示されます。

## あ行

受渡（うけわたし）
:   約定した取引について、証券と代金を実際にやり取りすること。「決済」とほぼ同じ意味で使われます。受渡を行う日を「受渡日」と呼びます。→ [約定から決済まで：T+2とは](flow/settlement-t2.md)

疑わしい取引の届出（うたがわしいとりひきのとどけで）
:   取引で受け取った財産が犯罪収益である疑いがあるときなどに、証券会社などの特定事業者が行政庁へ届け出る義務（犯罪収益移転防止法第8条）。届け出たことを顧客に漏らしてはいけません。→ [マネロン対策（犯収法）](rules/aml.md)

追証（おいしょう）
:   信用取引で、損失などにより委託保証金が一定の水準を下回ったときに、追加で差し入れる保証金。→ [信用取引](products/margin-trading.md)

## か行

株式数比例配分方式（かぶしきすうひれいはいぶんほうしき）
:   上場株式の配当を、証券会社の口座で保有株数に応じて受け取る方式。NISA口座で保有する上場株式の配当が非課税になるのは、この方式で受け取る場合です。→ [NISAの仕組み](tax/nisa.md)

元本払戻金（がんぽんはらいもどしきん）
:   投資信託の分配金のうち、実質的に投資した元本の一部が払い戻されたものとみなされる部分。「特別分配金」とも呼ばれ、課税されません（所得税法第9条第1項第11号）。→ [投資信託](products/investment-trusts.md)

基準価額（きじゅんかがく）
:   投資信託の値段のことで、1口あたりの純資産額。一般に1万口あたりで表示され、営業日ごとに1日1回計算されます。→ [投資信託](products/investment-trusts.md)

逆日歩（ぎゃくひぶ）
:   制度信用取引で、売りに使う株が不足したときに売り方が負担する品貸料。株の需給によって発生します。→ [信用取引](products/margin-trading.md)

共通KPI（きょうつうケーピーアイ）
:   投資信託の販売会社が、共通の定義で公表する成果指標。運用損益別の顧客比率など3つの指標があり、会社どうしを比較できるようにしたものです。→ [顧客本位の業務運営](rules/fiduciary.md)

## さ行

指値注文（さしねちゅうもん）
:   「この価格以下で買う」「この価格以上で売る」と、価格を指定して出す注文。→ [注文の出し方](flow/order-types.md)

重要事実（じゅうようじじつ）
:   上場会社などに関する未公表の重要な情報で、決定事実・発生事実・決算情報・その他投資判断に著しい影響を及ぼすもの（バスケット条項）にあたるもの（金融商品取引法第166条第2項）。インサイダー取引規制の対象になります。→ [インサイダー取引規制](rules/insider-trading.md)

証拠金（しょうこきん）
:   先物・オプション取引で差し入れる担保。清算機関（JSCC）が計算する額をもとに証券会社が設定し、相場に応じて毎日変わります。→ [デリバティブ入門](products/derivatives.md)

信託報酬（しんたくほうしゅう）
:   投資信託を保有している間、信託財産から日々差し引かれる費用。販売会社・運用会社・受託会社の報酬にあてられます。→ [投資信託](products/investment-trusts.md)

清算（せいさん）
:   多数の取引をとりまとめ、誰が誰に何をいくら渡すかを確定させる手続き。取引所取引では清算機関（JSCC）が担います。→ [清算と決済の仕組み](flow/clearing.md)

損益通算（そんえきつうさん）
:   上場株式などの売却損を、同じ年の売却益や（申告分離課税を選んだ）配当と差し引きすること。確定申告で行い、引ききれない損失は翌年以降3年間繰り越せます。→ [譲渡益・配当の課税と損益通算](tax/capital-gains.md)

## た行

立会（たちあい）
:   取引所で売買が行われる時間帯のこと。→ [株価はどう決まる？](market/price-formation.md)

建玉（たてぎょく）
:   信用取引や先物・オプション取引で、まだ反対売買などで決済していない取引（ポジション）。→ [信用取引](products/margin-trading.md)

単元株（たんげんかぶ）
:   会社が定める株式の1単位。国内の取引所では売買単位にもなっており、2018年10月1日以降、東証の内国株は100株に統一されています。→ [株式](products/stocks.md)、[注文の出し方](flow/order-types.md)

適合性の原則（てきごうせいのげんそく）
:   顧客の知識・経験・財産の状況・投資目的に照らして、不適当な勧誘をしてはならないというルール（金融商品取引法第40条第1号）。→ [適合性原則と説明義務](rules/suitability.md)

投資者保護基金（とうししゃほごききん）
:   証券会社が破綻し、分別管理の不備などで顧客の資産を返せない場合に、顧客1人あたり1,000万円を上限に補償する仕組み。値下がりによる損失は補償の対象外です。→ [顧客資産の保護](flow/asset-protection.md)

特定口座（とくていこうざ）
:   証券会社が上場株式などの1年間の損益を計算し、年間取引報告書を作成する口座。「源泉徴収あり」を選ぶと、確定申告をしなくてもよい場合があります。→ [特定口座と一般口座](tax/specified-account.md)

## な行

成行注文（なりゆきちゅうもん）
:   価格を指定せず「いくらでもよいので売買する」注文。→ [注文の出し方](flow/order-types.md)

ネッティング
:   互いに受け渡す証券や代金を差し引きし、差額だけを決済すること。清算機関（JSCC）が間に入ることで、より効果的に行えます。→ [清算と決済の仕組み](flow/clearing.md)

## は行

非課税保有限度額（ひかぜいほゆうげんどがく）
:   NISAで非課税で保有できる生涯の上限額。1,800万円（うち成長投資枠は1,200万円まで）で、買ったときの金額（簿価）で管理されます。→ [NISAの仕組み](tax/nisa.md)

分別管理（ぶんべつかんり）
:   証券会社が、顧客から預かった資産を自社の資産と分けて管理すること（金融商品取引法第43条の2）。→ [顧客資産の保護](flow/asset-protection.md)

振替（ふりかえ）
:   株式などの権利の移転を、紙の証券ではなく口座の記録（帳簿）の書き換えで行うこと。株式等の振替はほふり（証券保管振替機構）が運営する制度で行われます。→ [清算と決済の仕組み](flow/clearing.md)

法人関係情報（ほうじんかんけいじょうほう）
:   上場会社などの運営・業務・財産に関する未公表の重要な情報で、顧客の投資判断に影響を及ぼすと認められるものなど。証券会社がこれを提供して勧誘することは禁止されています。→ [インサイダー取引規制](rules/insider-trading.md)

## や行

約定（やくじょう）
:   売り注文と買い注文が成立し、売買が決まること。約定した日を「約定日」と呼びます。→ [約定から決済まで：T+2とは](flow/settlement-t2.md)

呼値の単位（よびねのたんい）
:   注文で指定できる価格の刻み。銘柄や株価の水準によって異なります。→ [株価はどう決まる？](market/price-formation.md)

## ら行

利回り（りまわり）
:   投資した金額に対する1年あたりの収益の割合。債券では、表面利率だけでなく買ったときの価格によって変わります。→ [債券](products/bonds.md)

リスクベース・アプローチ
:   自社が直面するマネー・ローンダリングなどのリスクを特定・評価し、リスクに見合った対策をとる考え方。金融庁のマネロンガイドラインの中心となる考え方です。→ [マネロン対策（犯収法）](rules/aml.md)

## 英字

DVP決済（ディーブイピーけっさい）
:   証券の受け渡しと代金の支払いを連動させ、一方だけが行われることがないようにする決済方法。→ [清算と決済の仕組み](flow/clearing.md)

PTS（ピーティーエス）
:   私設取引システム。証券会社が国の認可を受けて運営し、取引所と同じように売り注文と買い注文を付け合わせる仕組みです。→ [取引所とPTS](market/exchanges-pts.md)

SQ（エスキュー）
:   特別清算指数。先物・オプションの満期に、残っている建玉を清算する基準となる値です。日経225先物などでは、各限月の第2金曜日に算出されます。→ [デリバティブ入門](products/derivatives.md)
