# 出典・引用ポリシー

## 使う情報源

本サイトは、次のような**公開されている一次情報**だけを根拠にします。社内資料・非公開情報は使いません。

| 分野 | 主な情報源 |
|---|---|
| 法令・制度 | [e-Gov法令検索](https://laws.e-gov.go.jp/)、[金融庁](https://www.fsa.go.jp/) |
| 業務ルール | [日本証券業協会](https://www.jsda.or.jp/)、[日本取引所グループ（JPX）](https://www.jpx.co.jp/) |
| 清算・決済 | [日本証券クリアリング機構（JSCC）](https://www.jpx.co.jp/jscc/)、[証券保管振替機構（ほふり）](https://www.jasdec.com/) |
| 商品 | [資産運用業協会](https://www.imaj.or.jp/)（2026年4月1日に投資信託協会と日本投資顧問業協会が合併して発足[^imaj]） |
| 税制 | [国税庁](https://www.nta.go.jp/) |
| 事例 | [証券取引等監視委員会](https://www.fsa.go.jp/sesc/) |
| マネロン対策 | [警察庁 犯罪収益移転防止対策室（JAFIC）](https://www.npa.go.jp/sosikihanzai/jafic/index.htm) |

!!! tip "法令の条文を確認するには"
    e-Gov法令検索の条文ページは `https://laws.e-gov.go.jp/law/<法令ID>` の形式です（例：金融商品取引法は `323AC0000000025`）。e-Gov には無料の[法令API](https://laws.e-gov.go.jp/apitop/)もあり、条文の取得や改正チェックを自動化できます。

[^imaj]: [金融庁「認定金融商品取引業協会一覧」](https://www.fsa.go.jp/koueki/koueki10b.html)、[金融庁「業界団体との意見交換会において金融庁が提起した主な論点」（2026年6月）](https://www.fsa.go.jp/common/ronten/202606/07.pdf)

## 引用のルール

- **法令の条文**は著作権の対象外（[著作権法第13条第1号](https://laws.e-gov.go.jp/law/345AC0000000048)）のため、必要な範囲で引用できます。条番号を明記します。
- **協会規則・取引所資料・書籍・他サイトの文章**は転載しません。自分の言葉で要約・解説し、出典へのリンクを付けます。
- 図表は自作します。他者の図表をそのまま使う場合は、権利者の利用条件を確認します。
- 各記事の冒頭メタ情報（`sources`）に出典名とURLを、`last_reviewed` に一次情報と照合した日を記録します。

## 鮮度の管理

- `last_reviewed` から **180日** を過ぎた記事は、自動チェックで「要再確認」として一覧化されます。
- 制度改正の情報を見つけたら、影響する記事を洗い出して更新します。
